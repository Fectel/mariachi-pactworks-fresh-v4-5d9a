# PactWorks v4.6A10 — Full bilingual hosted contract

Spanish is the default. The first-open language chooser remains. All hosted customer-facing labels, tips, signing prompts, Zelle/payment instructions, statuses, print controls, event/money labels, and the canonical default Terms and Conditions now switch between Spanish and English.

The frozen contract source remains unchanged. The Spanish terms are a display translation of the canonical default terms, so switching languages does not mutate the signed payload.

No Supabase migration required.
