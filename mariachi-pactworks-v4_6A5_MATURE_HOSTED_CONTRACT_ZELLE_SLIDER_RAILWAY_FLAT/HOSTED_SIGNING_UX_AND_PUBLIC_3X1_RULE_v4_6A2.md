# PactWorks v4.6A2

- Hosted signing is now a simple shareable `/sign/<secure-token>` web link.
- Email delivery is optional; admin may copy/open/send the link manually.
- Re-clicking an existing locally stored link copies it instead of creating a duplicate.
- Backend same-version reissue rotates the token only for unsigned, unchanged frozen contracts.
- Legacy `.pactsigned` controls moved under More actions.
- 3 mariachis × 1 hour remains admin-only and is excluded from all public/customer pricing and scheduling.
- Public 1-hour performances begin at 4 mariachis.
- 3 mariachis × 30 minutes remains public.
