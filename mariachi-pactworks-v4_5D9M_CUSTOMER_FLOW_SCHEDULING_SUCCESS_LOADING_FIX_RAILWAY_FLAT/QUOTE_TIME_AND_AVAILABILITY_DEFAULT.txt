PactWorks v4.5D9B

BASIC QUOTE / INQUIRY
Now collects:
- selected package
- event type
- name
- phone
- email
- date if known
- preferred time if known
- city/location
- message
- referral context

The time input uses 15-minute increments but does NOT run the advanced
availability engine. It is simply a preferred time for the inquiry/CRM.

ADVANCED CHECK AVAILABILITY
Still controlled by:
Admin → Public portal connection → Show public “Check availability” scheduling

DEFAULT:
OFF

When OFF:
- customer sees the basic Quote / Inquiry path
- advanced Check Availability controls are hidden
- direct attempts to start the performance scheduler fall back to Quote

When ON:
- Check Availability becomes visible
- advanced Schedule & Quotes can be used

No database changes.
Railway/Docker remains canonical.
