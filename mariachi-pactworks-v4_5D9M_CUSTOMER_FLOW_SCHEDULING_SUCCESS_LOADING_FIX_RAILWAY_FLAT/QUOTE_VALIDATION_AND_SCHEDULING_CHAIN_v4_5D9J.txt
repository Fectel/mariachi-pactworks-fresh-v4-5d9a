PactWorks v4.5D9J

FIX 1 — QUOTE EVENT TYPE
The visible qEventType dropdown is now the canonical submitted event type.
The old quoteEvent variable is no longer used by quotePayload.

FIX 2 — REQUIRED FIELD VALIDATION
Required quote fields:
- Name
- At least one contact method: phone or email
- Event type
- Duration

Missing fields:
- turn red
- show inline error text where applicable
- show a summary message
- scroll/focus the first missing field
Validation clears as the user corrects the field.

Date, event time, location, and notes remain optional in the simple quote flow.

FIX 3 — SCHEDULING MODE
Dynamic Check Availability buttons now apply the freshest admin setting after
they are rendered. The scheduler refreshes config again immediately before
opening. When Quote + Scheduling is ON, the selected package shows both Quote
and Check Availability and Check Availability opens the calendar workflow.

No database changes.
