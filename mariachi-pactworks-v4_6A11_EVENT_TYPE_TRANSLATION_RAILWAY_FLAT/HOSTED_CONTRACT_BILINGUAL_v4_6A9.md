# PactWorks v4.6A9 — Bilingual Hosted Contract

No Supabase migration required.

Hosted `/sign/<token>` page:
- defaults to Spanish
- first open shows language chooser: Español / English
- if no stored choice exists, Spanish remains the default
- chosen language is remembered on that browser/device
- compact language switch remains available on the page

Translated UI includes:
- review/signing instructions
- acceptance prompts
- Zelle/payment controls
- screenshot instructions
- payment/reservation status
- Print / Save Signed Contract controls

The frozen contract terms themselves are not machine-translated by the language switcher.
Their original legal wording remains unchanged.
