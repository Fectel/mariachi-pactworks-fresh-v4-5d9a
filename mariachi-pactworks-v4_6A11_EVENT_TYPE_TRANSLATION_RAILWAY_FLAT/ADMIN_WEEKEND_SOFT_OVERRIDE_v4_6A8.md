# PactWorks v4.6A8 — Admin Weekend Soft Override

No Supabase migration required.

In `/app` and `/admin`, the Friday/Saturday 5–8 PM two-hour minimum is now an advisory rule for admins. Shorter packages remain visible. Choosing a package under two hours prompts for an explicit admin override before applying it.

Public/customer pricing and booking files are unchanged from v4.6A7, so public rules remain exactly as previously deployed.

Distance/service-area minimums remain hard rules.
